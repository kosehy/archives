# English Summary

Oscar Poke argues that AI-assisted development is changing the meaning of software hackathons. At a recent 48-hour hackathon in Vilnius, his two-person team connected an old rotary phone to a Raspberry Pi and a server over WebSocket. The phone handled two-way audio, bell ringing, and hang-up state, while an AI agent researched music, built playlists, and played niche requests through the Spotify API with an ElevenLabs voice persona.

The striking part was that the team reportedly did not look at a single line of code all weekend. Because the demo only needed to work, not be internally elegant, the effort shifted from typing code to designing the whole system and tuning how physical hardware met software services.

The essay’s main claim is that ordinary software hackathon projects, especially web apps, have become less impressive because AI tools can now produce them quickly. To make hackathons feel ambitious again, Poke expects more attention on hardware and old consumer technology: Apple II apps, fax-machine social networks, Game Boy Bloomberg terminals, LLM cash registers, AI microwaves, and other deliberately ridiculous physical systems.
