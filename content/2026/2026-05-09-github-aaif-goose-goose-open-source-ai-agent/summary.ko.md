# 공유 요약 - aaif-goose/goose

## 한 줄 요약

Goose는 로컬 데스크톱 앱, CLI, API로 동작하는 오픈소스 범용 AI 에이전트이며, 코드 보조를 넘어 리서치, 작성, 자동화, 데이터 분석, 개발 워크플로우를 한 에이전트 환경에 묶으려는 프로젝트다.

## 핵심 포인트

- 현재 저장소: `aaif-goose/goose`
- 라이선스: Apache-2.0
- 주 언어: Rust
- 기본 브랜치: `main`
- 스타/포크: 44748 stars / 4568 forks at capture
- 공식 설명: an open source, extensible AI agent that goes beyond code suggestions - install, execute, edit, and test with any LLM
- 공식 홈페이지: https://goose-docs.ai/
- README 기준 주요 기능: 데스크톱 앱, CLI, API, 여러 LLM provider, ACP provider, MCP extension 연결
- 현재 README는 프로젝트가 `block/goose`에서 AAIF, Linux Foundation 산하로 이동했다고 밝힌다.

## Hermes 관점에서 중요한 이유

- Hermes와 같은 에이전트 환경을 비교할 수 있는 공개 레퍼런스다.
- MCP, extension, provider-agnostic 구조, 로컬 실행, CLI/desktop/API라는 축이 Hermes의 tools, skills, cron, memory, gateway 구조와 비교 가능하다.
- 앞서 보존한 LinkedIn 글의 노동/오픈소스 논지를 검증할 때, Goose 자체에 대한 공식 근거로 사용할 수 있다.

## 주의할 점

- GitHub 저장소는 Goose의 기능과 생태계 존재를 보여주는 공식 근거다.
- 다만 Goose가 특정 규모의 인력 감축을 직접 대체했다는 노동 인과를 증명하지는 않는다. 그런 주장은 별도 출처 검증 자료와 조직/보도 자료 검증이 필요하다.
