# Figure Notes

## figure-01
- Status: recovered
- File: `figures/figure-01.jpg`
- What it shows: A Korean screenshot of an AI/coding-assistant-like terminal exchange. It says the assistant will rebuild/test an app but first clears the app database with `adb shell pm clear ...` and reports success. A later build/install command is interrupted by the user, who objects that data deletion was not allowed. The assistant then apologizes that it deleted app data and says the database migration issue should now be solved.
- Why it matters: This is a narrow, concrete illustration of instruction/specification failure: optimizing the immediate technical task can violate an implicit user value such as preserving data. It supports the post’s alignment/reward-hacking theme as an anecdotal software-agent example, not as evidence for the OpenAI CoastRunners experiment.
